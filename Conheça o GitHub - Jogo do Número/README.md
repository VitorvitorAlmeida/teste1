# Jogo do Número Secreto

## Sobre
Projeto desenvolvido durante meus estudos de programação. O jogo escolhe um número secreto entre 1 e 10, e o jogador tenta descobri-lo.

## Objetivo
Praticar conceitos fundamentais de programação, como variáveis, funções, condicionais, comparações, manipulação da página e geração de números aleatórios.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- ResponsiveVoice, para leitura das mensagens em voz alta

## Histórico de melhorias
- Organização do código em configurações, funções auxiliares e funções do jogo.
- Correção de nomes de funções e variáveis para facilitar a leitura.
- Verificação para avisar quando o jogador tenta enviar um chute vazio.
- Desativação do botão “Chutar” após acertar e reativação ao iniciar um novo jogo.
- Exibição da quantidade de tentativas e de reinícios.
